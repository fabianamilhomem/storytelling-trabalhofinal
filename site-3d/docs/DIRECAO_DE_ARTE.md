# Direção de arte

## Três direções avaliadas
| | A. Cartório Mineral Claro | B. Planta Normativa | C. Vitrine de Acrílico |
|---|---|---|---|
| Ideia | Arquivo público: calcário, papel, latão | Prancha de projeto: linhas azuis sobre papel quadriculado | Camadas translúcidas de acrílico e vidro |
| Coerência acadêmica | Alta (documento, rigor) | Muito alta (precisão, arquitetura) | Média |
| Legibilidade em sala clara | Alta | Média (linhas finas) | Baixa (transparência reduz contraste) |
| Personalidade | Alta | Média | Alta, porém genérica ("tech") |
| Potencial cinematográfico | Alto | Médio | Alto |
| Visualizações científicas | Boas | Ótimas | Arriscadas |
| Desempenho | Bom | Ótimo | Pior (transmissão) |

## Escolha: A + B, com acrílico apenas como detalhe
Superfícies de papel/calcário claras (legibilidade), linhas de projeto azul-planta como estrutura espacial e instrumento (eixos, cotas, réguas), latão para marcação da norma, acrílico só em placas de "evidência" na cena 3D.
